## 阅读路线

- **共同基础**：机器学习理论 → 线性回归与分类 → 神经网络基础与训练机制；NumPy 与 PyTorch 可配合模型实现阅读。
- **语言模型**：循环网络与序列建模 → Attention 与 Transformer → 文本表示与语言建模 → 语言模型预训练与微调 → 文本生成与解码。
- **多模态**：卷积网络与视觉模型、Attention 与 Transformer → 学习范式中的对比学习 → CLIP 与图文对齐 → 图文融合与视觉语言模型；结合多模态任务与评价及项目实践。
- **强化学习**：强化学习基础 → 多臂老虎机 → 价值估计与表格型控制 → DQN → 策略梯度与 Actor–Critic。
